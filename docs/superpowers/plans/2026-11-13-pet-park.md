# Pet Park Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Pet Park. Three original mini games (Egg Catch, Pop-up Pets, Pet Memory) star her own pets. She pays for each play with a 🎟️ ticket, earned by doing well at math.

**Architecture:**
- Ticket, unlock and best-score rules live in the testable engine (`<script id="engine">`).
- The screens live in `<script id="game">`. One shared game shell handles the intro card, the frame loop, the timer, quitting and the results card.
- Each game plugs into the shell as an object in `GAME_UI`.
- Sprites are the existing `creatureSVG()` strings in absolutely positioned elements, moved every frame.

**Tech Stack:** Plain JS/HTML/CSS in one file (`index.html`), `node test-engine.mjs` for engine tests, and the built-in browser for play-testing.

**Spec:** `docs/superpowers/specs/2026-11-13-mini-games-design.md`

## Global Constraints

- One static file. No new libraries, no CDN scripts.
- Work in a git worktree on branch `mini-games`, cut from `main`. Commit only to that branch. Never push, never merge. Pushing `main` deploys the live site.
- `node test-engine.mjs` must exit 0 before every commit. Read the exit code, then commit in a separate call.
- Games give **no seeds and no stars**. Only bests are saved.
- Unlock levels: Egg Catch 2, Pop-up Pets 4, Pet Memory 6.
- Ticket rules:
  - a round with `ok >= asked * 0.75` (and `asked > 0`)
  - a boss win
  - the daily all-quests bonus
  - They stack, with no cap.
- One ticket is spent per game, at Start, and the save is written right away.
- Every game is fully playable by keyboard alone and by mouse alone.
- Copy is kid-readable and in the game's playful voice. No em dashes in kid-facing text.

## Review Focus

1. **`render()` running mid-game.** The 🔊 button and the Quit arm both re-render. The game must keep going with its score and sprites intact (Task 3 step 6).
2. **A double-click or double Enter on Start** must spend exactly one ticket (Task 3 step 6).
3. **A hidden tab mid-game.** The timer must pause, not run out (Task 3 step 6).
4. **A player with almost no pets.** Level 2, no hatched pets, one warm egg: every game still starts and looks right (Task 1 test, Task 6 step 2).
5. **Keys leaking between screens.** Digits, arrows and Enter in a game must not trigger round, home or boss handlers. Enter on Home must still start a round (Task 3 step 6, Task 6 step 2).

- Add: copy `docs/superpowers/specs/2026-11-13-mini-games-design.md` and this plan into the worktree's `docs/`

**Interfaces:**
- Produces:
  - `E.GAMES`: `[{ id: 'catch', name: 'Egg Catch', icon: '🥚', level: 2, fewer: false }, { id: 'pop', name: 'Pop-up Pets', icon: '🐹', level: 4, fewer: false }, { id: 'memory', name: 'Pet Memory', icon: '🃏', level: 6, fewer: true }]`
  - `E.gamesOpen(save) → string[]`: ids of the games open at her level
  - `E.startGame(save, id, now) → boolean`: spends one ticket and adds 1 to `days[key].games`. Returns false (with no change) when the id is unknown, the game is locked, or she has no tickets.
  - `E.gameFinish(save, id, score) → { best: boolean }`: writes `save.arcade.best[id]`. Lower is better when `fewer`. A score ≤ 0 is never a best.
  - `E.petRoster(save) → [{ id, stage, wear }]`:
    - every fact at stage 1 to 4, across the current subject and `save.tracks`
    - sorted by stage, highest first; within a stage the current subject comes first, then subject fact order
    - `wear` is that subject's `worn[id] || {}`
  - New save fields: `tickets: 0`, `arcade: { best: {} }`. Day entries gain `tix` and `games`, added only when they first change (older days have neither).
  - Internal `giveTicket(save, now)`: adds to `save.tickets` and to `days[key].tix`.
- `finishRound`'s and `questEvent`'s return values stay exactly as they are today (an existing test deep-equals them).

test('pet park tickets: a great round, a boss win and all quests each earn one, and they stack', () => {
  let now = new Date(2026, 0, 5, 16).getTime();
  const save = E.newSave(now, 'times', 'T');
  assert.equal(save.tickets, 0);
  const round = (ok, asked) => Object.assign(E.startRound(), { ok, asked });
  save.quests = { day: E.dateKey(now), run: 0, bonus: true, list: [] };
  E.finishRound(save, round(9, 12), now); assert.equal(save.tickets, 1, '9 of 12 earns one');
  E.finishRound(save, round(8, 12), now); assert.equal(save.tickets, 1, '8 of 12 does not');
  E.finishRound(save, round(3, 4), now); assert.equal(save.tickets, 2, 'a short round at 75% counts');
  E.finishRound(save, round(0, 0), now); assert.equal(save.tickets, 2, 'an empty round earns nothing');
  assert.equal(save.days[E.dateKey(now)].tix, 2);
  const g = E.SUBJECTS.times.groups.find(x => x.key === 'x7');
  for (const id of g.ids) save.facts[id] = { s: 3, due: E.dayStart(now, 2), seen: 1, r: 2, w: 0, last: 0 };
  const boss = E.startBoss(save, 'x7', now, seeded(4));
  let res; for (let i = 0; i < 10; i++) res = E.bossAnswer(save, boss, boss.qs[boss.i].ans, now);
  assert.equal(res.over, 'win'); assert.equal(save.tickets, 3, 'a boss win earns one');
  save.quests = { day: E.dateKey(now), run: 0, bonus: false, list: [{ type: 'rounds', goal: 1, n: 0, done: false }] };
  E.finishRound(save, round(0, 12), now); assert.equal(save.tickets, 4, 'all quests done earns one');
  E.finishRound(save, round(0, 12), now); assert.equal(save.tickets, 4, 'the quest ticket is paid once a day');
  now = E.dayStart(now, 1) + 9 * HOUR;
  save.quests = { day: E.dateKey(now), run: 0, bonus: false, list: [{ type: 'rounds', goal: 1, n: 0, done: false }] };
  E.finishRound(save, round(12, 12), now); assert.equal(save.tickets, 6, 'great round + last quest = 2');
  assert.equal(save.days[E.dateKey(now)].tix, 2);
});

test('pet park games: unlock by level, cost one ticket, keep bests, pay nothing', () => {
  const now = new Date(2026, 0, 5, 16).getTime();
  const save = E.newSave(now, 'times', 'T');
  assert.deepEqual(E.GAMES.map(g => [g.id, g.level]), [['catch', 2], ['pop', 4], ['memory', 6]]);

  assert.equal(E.startGame(save, 'nope', now), false);
  assert.equal(save.tickets, 1);

  assert.equal(save.tickets, 0);
  assert.equal(save.days[E.dateKey(now)].games, 1);
  assert.equal(E.startGame(save, 'catch', now), false, 'one ticket, one game');
  const seeds = save.seeds, stars = save.stars;
  assert.deepEqual(E.gameFinish(save, 'catch', 0), { best: false });
  assert.deepEqual(E.gameFinish(save, 'catch', 12), { best: true });
  assert.deepEqual(E.gameFinish(save, 'catch', 9), { best: false });
  assert.deepEqual(E.gameFinish(save, 'memory', 14), { best: true });
  assert.deepEqual(E.gameFinish(save, 'memory', 18), { best: false });

test('pet park saves: old saves get no tickets, bad data is fixed, tickets travel across subjects', () => {
  const now = new Date(2026, 0, 5, 16).getTime();
  const save = E.newSave(now, 'times', 'T');
  const old = JSON.parse(JSON.stringify(save)); delete old.tickets; delete old.arcade;
  const p = E.repair(old, now);
  assert.deepEqual([p.tickets, p.arcade], [0, { best: {} }]);
  const j = E.repair(Object.assign(JSON.parse(JSON.stringify(save)), { tickets: -4, arcade: { best: { catch: 'x', pop: 7.6, memory: -2, nope: 5 } } }), now);
  assert.deepEqual([j.tickets, j.arcade], [0, { best: { pop: 7 } }]);
  assert.deepEqual(E.repair(JSON.parse(JSON.stringify(j)), now), j, 'loading twice changes nothing');
  assert.deepEqual(E.repair(Object.assign(JSON.parse(JSON.stringify(save)), { arcade: 'broken' }), now).arcade, { best: {} });

  assert.deepEqual([save.tickets, save.arcade.best.catch], [3, 20]);

### Task 3: Game shell + Egg Catch

**Files:**
- Modify: `index.html` (`inGame`, `leaveGame`, `render`, `ACTS`, the `keydown` handler, a new `keyup` and a delegated `pointermove` on `#app`, a new `vGame`, plus CSS)

**Interfaces:**
- Consumes: `E.startGame`, `E.gameFinish`, `E.petRoster`, `creatureSVG`, `spec`, `sfx`, `bossSVG`
- Produces (Tasks 4 and 5 plug into these):
  - `ui.game = { id, phase: 'intro'|'play'|'over', score, left /* ms, Infinity when untimed */, last, end /* set true to finish */, res, ...gameState }`
  - `GAME_UI[id] = { secs, label /* 'Score' or 'Moves' */, intro /* how-to-play HTML */, setup(g), html(g), frame(g, dt), key?(g, e, down), hit?(g, dataset), point?(g, e) }`
  - `openGame(id)`, `gameStart()`, `gameEnd()`
  - `parkPets(n) → [{ id, stage, wear }]`, n items:
    1. hatched pets from `E.petRoster`, shuffled
    2. then warm and cracking eggs, keeping only one egg per look (`spec(id).egg + '|' + spec(id).pat`)
    3. then cold eggs from the current subject drawn at stage 1, under the same look rule
  - Arena coordinates are logical: `W = 1000`, `H = 600`, mapped to the arena's real size.

- [ ] **Step 1: Build the shell**
  - `openGame(id)` shows the intro card: game name, `GAME_UI[id].intro`, "Costs 1 🎟️ · you have N", `[Start ▶]` (Enter works too) and `[← Pet Park]`.
  - `gameStart()` runs only when `phase === 'intro'`:
    - if `E.startGame` returns false, go to the park screen
    - otherwise `persist()`, `setup`, `phase = 'play'`, `left = secs * 1000 || Infinity`, `render()`, and start the `requestAnimationFrame` loop
  - The loop:
    - `dt = g.last ? Math.min(t - g.last, 50) : 0` (the clamp is what pauses the timer while the tab is hidden)
    - `left -= dt`, then `frame(g, dt)`
    - writes the score and time into `#gscore` and `#gtime` by `textContent`
    - calls `gameEnd()` once `left <= 0` or `g.end`
  - `gameEnd()`:
    - cancels the loop, runs `E.gameFinish`, then `persist()`
    - sets `phase = 'over'` and `ui.lock = now + 900`
    - plays `sfx(best ? 'grown' : 'done')`
    - shows the results card: score, "NEW BEST!" or "Your best is N", `[🎪 Pet Park] [Home]`
  - Top bar during play: `[← Quit]`, name, `label N`, `⏱ Ns` (hidden when untimed) and the sound button. Quit takes two presses (`ui.arm = 'quit'`, button text "Tap again to quit"). The second press runs `go('park')`.
  - `inGame()` includes `'game'`. `leaveGame()` cancels the loop and nulls `ui.game`. The mic is never started on this screen.
  - Keys:
    - `keydown` starts with `if (ui.screen === 'game') { gameKey(e, true); return; }`, and `keyup` calls `gameKey(e, false)`.
    - `gameKey`: intro, Enter starts; over, Enter after the lock goes to the park; play goes to `GAME_UI[id].key`.
    - Enter and Space on a focused button keep their native click.
  - Clicks: `data-act="gamestart" | "gamequit" | "gamehit"` (the last passes the dataset to `GAME_UI[id].hit`). `pointermove` on `#arena` goes to `point`.
  - **Every `frame` re-creates any sprite element that is no longer connected**, because `render()` can run mid-game.

- [ ] **Step 2: Build `GAME_UI.catch`**

  - Hold ← → or A D to move about 0.9 units/ms. `point` sets a target x the catcher glides to.
  - The spawn gap goes from 900 ms to 450 ms, and fall speed from 0.25 to 0.5 units/ms, both linearly over the minute.
  - Egg types:
    - warm eggs of her facts (`creatureSVG(id, 1)`): +1
    - 8% golden egg (its own small SVG, with a sparkle): +3

  - A catch is the egg's bottom inside the catcher's top band with `|dx| < 70`. Missed eggs cost nothing.
  - Sounds: `sfx('right')` for a catch, `sfx('wrong')` for a stinky one.
